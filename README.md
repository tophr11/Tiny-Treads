# 🪖 Tiny Treads

A tower defense prototype where the invaders are **tanks**.
Place your defenses, stop the armored waves, and don't let a single tread reach your base.

> 🚧 **Just getting started:** This project is brand new. Right now it only has
> a tilemap and an enemy path. Tank movement, towers, and waves are still to come.

## About the Game

Tiny Treads is a tower defense game about holding the line against tank
columns. The goal is to place defenses along the path and stop each wave before
it reaches your base.
